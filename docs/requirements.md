# GrammerNote 요구사항 정의서

## 1. 문서 목적과 범위

서비스 요구사항을 기록합니다. 
AI와 개발자가 서비스에 필요한 기능과 동작을 동일하게 이해하기 위한 문서입니다.

이 문서는 요구사항을 정의하는 단계의 문서이며, 구현 완료를 의미하지 않습니다.
기술 스택, 데이터베이스, 데이터 모델, API, 화면 상세 설계, 배포 구성과 개발 순서는 
요구사항 정의가 완료된 뒤 구체화합니다. 

## 2. 서비스 목적

토익 공부 중 모르는 영문장을 저장하고, 문장 속 단어나 표현에 해석과 문법 메모를 연결해 다시 찾아볼 수 있는 개인 학습 노트 서비스를 제공합니다.


기본 사용 흐름은 **로그인 → 단어장 생성 → 영문장 저장 → 단어·표현 선택 및 필기 → 재조회 또는 검색**입니다.

## 3. 용어 정의

| 용어 | 정의 |
| --- | --- |
| 단어장 | 사용자가 문장들을 모아 관리하는 단위 |
| 문장 | 단어장에 저장하는 영문장과 선택적인 전체 해석·문장 메모 |
| 구간 | 문장 안에서 사용자가 선택한 단어 하나 또는 여러 단어로 이루어진 표현의 위치 |
| 필기 | 특정 구간에 연결해 작성하는 뜻, 문법 설명, 주의사항 등의 자유로운 기록 |

## 4. 기능 요구사항

### 4.1. 회원 및 접근 권한

초기 요구사항의 일반 회원가입·로그인은 후속 논의에 따라 구글 로그인으로 대체합니다.

| ID | 요구사항 |
| --- | --- |
| AUTH-01 | 사용자는 구글 로그인으로 서비스를 시작할 수 있다. 최초 로그인 시 회원으로 가입되며, 이후에는 동일 회원으로 로그인할 수 있다. |
| AUTH-02 | 사용자는 로그인 상태를 유지하고 로그아웃할 수 있다. |
| AUTH-03 | 로그인한 사용자는 자신의 단어장, 문장, 필기만 조회·생성·수정·삭제할 수 있다. |
| AUTH-04 | 다른 사용자의 학습 자료에 접근할 수 없으며, 첫 버전의 모든 학습 자료는 비공개로 저장한다. |

### 4.2. 단어장 관리

| ID | 요구사항 |
| --- | --- |
| BOOK-01 | 사용자는 단어장을 생성하고 자신의 단어장 목록을 조회할 수 있다. |
| BOOK-02 | 사용자는 단어장 이름과 설명을 수정할 수 있다. |
| BOOK-03 | 사용자는 단어장을 삭제할 수 있다. 삭제 전 포함된 문장과 필기도 함께 삭제된다는 안내와 확인 절차를 제공한다. |

### 4.3. 문장 관리

| ID | 요구사항 |
| --- | --- |
| SENT-01 | 사용자는 단어장을 선택하여 영문장을 등록할 수 있다. 영문장만 입력해도 저장할 수 있다. |
| SENT-02 | 전체 해석과 문장 전체에 대한 메모는 선택적으로 입력할 수 있다. |
| SENT-03 | 사용자는 저장한 문장의 목록과 상세 내용을 조회할 수 있다. |
| SENT-04 | 사용자는 문장의 내용과 소속 단어장을 수정할 수 있다. |
| SENT-05 | 사용자는 문장을 삭제할 수 있다. 삭제 전 연결된 필기도 함께 삭제된다는 안내와 확인 절차를 제공한다. |

### 4.4. 단어 및 표현별 필기

| ID | 요구사항 |
| --- | --- |
| NOTE-01 | 사용자는 문장에서 단어 하나 또는 여러 단어로 이루어진 구간을 선택할 수 있다. |
| NOTE-02 | 선택한 구간에 뜻, 문법 설명, 주의사항 등을 자유롭게 작성할 수 있다. 뜻·품사·문법을 각각 필수 항목으로 입력하도록 요구하지 않는다. |
| NOTE-03 | 하나의 문장에 여러 구간의 필기를 저장할 수 있다. |
| NOTE-04 | 필기가 연결된 구간을 문장에서 시각적으로 구분하고, 클릭하거나 탭하여 필기를 확인할 수 있다. |
| NOTE-05 | 사용자는 저장한 필기를 수정하거나 삭제할 수 있다. |
| NOTE-06 | 같은 단어가 문장에 여러 번 등장해도 선택한 위치별로 필기를 구분한다. |
| NOTE-07 | 영문장 원문을 수정하면 기존 필기를 보존하고, 연결할 구간을 다시 지정하도록 안내한다. |

### 4.5. 검색

| ID | 요구사항 |
| --- | --- |
| SEARCH-01 | 사용자는 자신의 전체 단어장 또는 특정 단어장 안에서 검색할 수 있다. |
| SEARCH-02 | 검색 대상은 영문장, 전체 해석, 문장 메모, 구간별 필기 내용이다. |
| SEARCH-03 | 검색 결과에서 해당 문장의 상세 화면으로 이동할 수 있다. |
| SEARCH-04 | 검색 결과가 없으면 안내 메시지를 표시한다. |

## 5. 사용성 요구사항

| ID | 요구사항 |
| --- | --- |
| UX-01 | PC와 모바일 브라우저에서 주요 기능을 사용할 수 있다. |
| UX-02 | 마우스를 올리는 동작 없이 클릭과 탭으로 필기를 확인할 수 있다. |
| UX-03 | 저장 성공 여부와 오류 발생 여부를 명확하게 표시한다. |
| UX-04 | 저장에 실패한 경우 작성 중인 입력 내용을 유지한다. |
| UX-05 | 저장하지 않은 내용이 있는 상태에서 화면을 벗어나면 안내한다. |
| UX-06 | 목록이 길어질 경우 페이지 단위로 나누어 조회한다. |

## 6. 보안 및 운영 요구사항

| ID | 요구사항 |
| --- | --- |
| SEC-01 | 서버에서 로그인 여부와 데이터 소유권을 검사한다. |
| SEC-02 | 실제 서비스는 HTTPS로 제공한다. |
| SEC-03 | 인증 정보 등 민감한 내용을 로그에 기록하지 않는다. |
| OPS-01 | 서버 오류를 확인할 수 있는 로그를 남긴다. |
| OPS-02 | 데이터베이스 백업 절차를 마련하고 복원 가능 여부를 확인한다. |

## 7. 첫 버전에서 제외하는 범위

- 다른 사용자의 단어장 검색 및 공개 공유
- 공동 편집과 공개 위키
- 공통 문법 사전 및 자동 링크
- AI 문장 분석과 해설 생성
- 자동 복습 일정 및 학습 통계
- 단어 등장 횟수에 따른 별 표시
- 관리자 전용 통계 화면
- 일반 이메일·비밀번호 회원가입 및 구글 외 로그인 제공자

## 8. 첫 출시 완료 기준

- 구글 로그인으로 가입하고 자신의 단어장을 만들 수 있다.
- 영문장만 입력하여 저장할 수 있다.
- 단어 또는 표현을 선택해 필기를 저장하고 다시 확인할 수 있다.
- 다시 로그인해도 저장한 문장과 필기를 확인할 수 있다.
- 검색으로 이전에 작성한 내용을 찾을 수 있다.
- 다른 사용자의 자료에 접근할 수 없다.
- 배포된 서비스에서 위 흐름이 정상적으로 동작한다.
