# GrammerNote

토익 공부 중 모르는 영문장을 저장하고, 문장 속 단어나 표현에 해석과 문법 메모를 연결해 다시 찾아볼 수 있는 개인 학습 노트 서비스입니다.

## 개발 문서

개발 문서는 `docs/` 폴더에서 관리합니다. AI와 개발자는 작업 전에 관련 문서를 확인합니다.

| 문서 | 내용 |
| --- | --- |
| [요구사항 정의서](docs/requirements.md) | 서비스 목적, 용어, 기능·사용성·보안·운영 요구사항, 첫 버전 범위와 출시 완료 기준 |

현재는 요구사항을 정의하는 단계입니다. 기술 구성과 상세 설계 문서는 요구사항 정의가 완료된 뒤 필요한 시점에 작성합니다.

## 문서 관리 원칙

- README는 프로젝트 소개와 개발 문서의 진입점으로 사용합니다.
- 요구사항의 기준 문서는 `docs/requirements.md`로 유지하며, 다른 문서에 같은 내용을 중복해서 관리하지 않습니다.
- 요구사항 ID는 유지하고, 삭제한 ID를 다른 요구사항에 재사용하지 않습니다.
- 요구사항이 변경되면 기준 문서를 수정하고, 구현 변경 시 관련 문서도 함께 갱신합니다.
- 요구사항과 구현 완료 상태를 구분합니다.
- 새로운 개발 문서를 작성하면 위 문서 목록에 링크를 추가합니다.
